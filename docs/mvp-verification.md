## 確認コマンド

`package.json` と `.npmrc` に指定した Node.js と pnpm を使用します。

```sh
pnpm install --frozen-lockfile
pnpm lint
pnpm test
pnpm generate
pnpm preview
```

ブラウザーのスモークテストは、プレビューを起動した状態で実行します。既存の `playwright-core` を使い、Chromium の実行ファイルを指定できます。

```sh
BASE_URL=http://localhost:3000 CHROMIUM_PATH=/usr/bin/chromium pnpm exec node e2e-tests/smoke.mjs
```
